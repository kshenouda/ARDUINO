# Arduino Projects

Sketches and small builds for the Arduino Uno, built to learn sensor inputs, servo/motor controls, serial protocols, and more.

## Run a project

1. Clone the repo: `git clone https://github.com/kshenouda/ARDUINO.git`
2. Open the project's `.ino` file in the Arduino IDE (or PlatformIO).
3. Select your board and port under Tools.
4. Install any libraries listed in that project's folder.
5. Wire the circuit as shown in the project's diagram, then upload.
